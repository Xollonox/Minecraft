# Version 9 character and challenge release

Version 9 is a focused character-model, creature-presentation and survival-difficulty upgrade. It is
not represented as an exact commercial-edition clone or completion of every item in the supplied
aspirational roadmap.

## Player-visible improvements

- World creation now offers Creative, Easy, Normal, Hardcore and the special Chug Tuff mode, with a
  plain-language description before play.
- Difficulty is owned by each save. Loading one world cannot silently change another world's rules.
- Easy reduces incoming damage, hunger pressure, hostile health, spawn rate and cap while improving
  natural regeneration.
- Hardcore increases combat and hunger pressure, permits lethal starvation and grants one life.
- Chug Tuff is the strongest one-life profile, with 1.75x incoming damage, 1.7x exhaustion, 1.55x
  hostile health, faster attacks, a higher hostile cap and more frequent spawn passes.
- A one-life death is persisted immediately. The death screen removes Respawn, and the world list
  marks the save as lost while retaining safe Export and Delete actions.
- Third-person view uses a new original articulated voxel avatar with a modeled face, layered hair,
  shirt panels, sleeves, forearms, trousers, boots, hand sockets and contact shadow.
- Shared mob rigs gain modeled muzzles, ears, hooves, facial depth, chest detail and feet. One
  instanced contact-shadow pool grounds all live creatures with one draw call.
- The HUD and world list show the active difficulty by name.

## Compatibility and asset policy

- World format 9 adds `difficulty` and `hardcoreDefeated`. Older saves migrate to Normal and remain
  playable; block ids and chunk edit formats are unchanged.
- The character and creature geometry is generated by project code. No downloaded Mojang skin,
  Minecraft model, or third-party creator asset is included.
- Existing v7/v8 progression, graphics and End-campaign behavior remains covered by compatibility
  tests.

## Verification

Run `npm run check` for the import audit, all deterministic suites, v7/v8 compatibility, v9 gates
and the production build. Run `npm run smoketest:browser` for the full production and instrumented
Chromium/WebGL campaign, including the five-option creation menu, third-person avatar, one-life UI,
High graphics, save/reload and End campaign.
